# example-team-repo

A stand-in for a team's Copilot-style `agent_and_skills` repository. It exists only
to test `../sync-team-agents.ps1` and the `skills` path in the OpenCode config.
The frontmatter is deliberately Copilot-shaped (`tools:` array, a `model:` OpenCode
does not know, `handoffs:`), because that is what the sync has to survive.
